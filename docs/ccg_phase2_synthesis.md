# CCG 第 2 轮（第二阶段方案）汇总与决策

参与：GPT-6-Astra（max）、Gemini-4-Argon（high）、Claude Opus 5.5（max 三次均因思考耗尽输出额度被截断——32k / 64k / 128k；第四次用 xhigh 成功）。原文：`round1/out_astra.md`、`round1/out_gemini.md`、`round1_opus_xhigh/out_opus.md`。

## 一致意见（直接采纳）

| 议题 | 决策 |
|---|---|
| 新增语言 T1（12 个） | zh-Hans 简体中文、zh-Hant 繁体中文（TW/HK 两套排印）、en 英文、ja 日文、ko 韩文、vi 越南文、th 泰文、tr 土耳其文、fa 波斯文、it 意大利文、pl 波兰文、nl 荷兰文 |
| 朝鲜（ko-KP） | 作为韩文的地区变体，不单列语言、不进开源版；不抓取朝鲜官方媒体；如需要，用规则把韩文正字法转换（头音法则、去汉字），仅内部实验 |
| 排版引擎 | 不再只按空格切词：中日按字切 + 避头尾禁则；泰文用浏览器 Intl.Segmenter 词典切词；韩文按词（keep-all）；越南文 NFC + 字体覆盖筛选 + 加行距；波斯文用 ی/ک 码位、波斯数字、保留 ZWNJ；土耳其文大小写 i/İ、ı/I |
| 数据主池 | FinePDFs（真实 PDF 正文，带 CommonCrawl 原件指针）为主，FineWeb-2 补新闻 / 杂志与低资源语种；维基百科（CC BY-SA）单列子集；内部 crop 图不进开源版 |
| 数据过滤 | 语种识别分、未截断、去重、文字纯度（防非 Unicode 字体乱码）、扫描件只取 OCR 质量高的；按内容类型匹配版式类型 |
| LLM 降本 | 正文尽量直接用真实文本，LLM 只做结构化编辑；论文 / 试卷等仍需整包生成；按（语种组 × 任务）分别选型 |
| 选型实验 | 小规模对比：候选 gpt-6.1-sol(low，基线)、deepseek-v4.1-flash、自部署 Qwen3.8-27B（不开 thinking）、Qwen3.5-9B、claude-sonnet-5-5 等；判据 = 质量达标前提下“每合格页成本”最低；评委不评同家族模型 |
| 真实评测集 | 框来自检测模型 + PDF 文字层，大模型只做合并 / 拆分 / 改类 / 排序与公式表格内容，不直接给坐标；文本以文字层为准并按文字系统校验；Gemini-4-Argon 不在被测名单，作主标注之一；报告“留一法”偏差；评测文档与合成正文池去重隔离 |
| 真实集许可 | 双层发布：A 层（CC BY / CC0 / 公有领域 / 政府开放）发图像 + 标注；B 层只发 URL、WARC 指针、页码、哈希、渲染脚本和标注，限研究用途 |
| 凑不齐的格 | 标 N/A、公布覆盖矩阵，不用合成页或别的语种凑数 |
| 模型评测口径 | 失败 / 拒答 / 截断照常计分（空输出），另报失败率；不支持的语种不剔除；ODB 官方分 + 保留组合附标（元音符号、声调）的补充文本指标；报告合成集与真实集的模型排名一致性 |
| 批量生产 | 先分阶段计时找瓶颈；引擎批量读写 DOM、浏览器常驻按（语种，类型）分桶、退化另起进程；产物改为大分片（不再每页 4 个小文件）；内容先批量生成入库（LLM 墙钟是瓶颈） |

## 有分歧的点（我的取舍）

| 议题 | 三方意见 | 采用 |
|---|---|---|
| Top-15 名单 | Astra / Opus：含乌尔都、不含泰文；Gemini：泰文换乌尔都（乌尔都 PDF 少） | 多数：**Top-15 = en、zh-Hans、hi、es、ar、fr、bn、pt、id、ur、ru、de、ja、vi、ko**；Top-20 再加 zh-Hant、tr、fa、th、it |
| 日文 / 繁中竖排 | Opus：本阶段必做（日文书报以竖排为主）；Gemini：报纸、书籍两类 20%；Astra：延后 | 本阶段做**书籍竖排**（ja、zh-Hant），竖排多栏报纸视进度再做 |
| 额外语言 T1b | Opus 建议加 uk 乌克兰、mr 马拉地、he 希伯来、ms 马来（复用现有引擎） | 列为 T1 签字后的可选扩展 |
| 产物格式 | Opus：Parquet 分片；Gemini / Astra：WebDataset tar + Parquet 索引 | Parquet 分片（图像 JPEG 字节一列 + manifest，HF 直接可读），附 WebDataset 转换脚本 |
| 开源版内容生成模型 | Opus：闭源 API 条款常限制用输出训练竞品模型，开源版优先开放权重模型（Qwen） | 选型实验里 Qwen3.8-27B 作为重点候选；最终视质量定，生成字段标注 generator |

## 需要用户决策 / 知悉

1. **真实评测集的人工核验**：三方都认为开源级金标必须经人工核验（Opus 估 1800 页 × 20 分钟 ≈ 600 人时；Gemini 估只审分歧页约 320 页、2~3 人天）。本流程只能做到“文字层 + 检测框 + 三模型结构标注 + 自动一致性检查”，会输出分歧页清单和核验页面，是否安排人工由用户定。
2. **“Top-20 × 每类 10k”**：按 20 个语种 × 每语种 1 万页 = 20 万页理解；若指 20 语种 × 9 类 × 1 万 = 180 万页，渲染约 6 小时、LLM 内容费用约千到万美元量级。
3. **价格**：网关不返回单价，成本先用“token 数 + 公开价量级假设”表示，拿到结算价后替换。
